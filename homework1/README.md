## Setup

Activate the virtual environment:

```bash
source .venv/bin/activate
```

Install the required packages:

```bash
python3 -m pip install -r requirements.txt
```

## Run All Tests

```bash
pytest -q
```

## Run an Individual Task

```bash
python3 src/task1.py
```

## Project Files

- `src/` has the code for Tasks 1 through 7.
- `tests/` has the pytest tests for each task.
- `task6_read_me.txt` is used in Task 6.
- `requirements.txt` lists the packages used in this project.
